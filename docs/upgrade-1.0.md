# 从旧版本升级（历史兼容）

1.0.0（2026-10 发布）引入不兼容的数据与 IPC 变化，本文保留旧用户升级、回退和历史数据兼容需要知道的事项。

- **设置与密钥**：公开 `settings:get` 从 1.0.0 起只返回配置元数据、`hasApiKey` 和凭据状态，不再返回 API Key；保存采用 `keep`/`replace`/`clear` 意图。密钥以 Electron `safeStorage` 的 OS 加密写入 schema 2 设置文件，旧版程序无法读取。
- **自动迁移**：旧版明文设置在主进程首次解析已保存私有凭据之前或保存设置之前触发迁移。迁移逐个转换主设置文件及受管理恢复副本；无法安全完成时报告 `migration-pending` 并保留未转换副本，稍后解析凭据、保存设置或执行受控恢复时可重试。每个文件替换是原子的，但主文件、备份和损坏快照之间没有跨文件事务。细节见 [credential-security.md](credential-security.md)。
- **升级前备份**：首次打开 1.0.0 前，建议退出应用并复制整个用户数据目录，至少保留 `settings.json` 及其受管理的 `.bak`、`.corrupt` 恢复文件。迁移开始后如需回退旧版，先关闭应用并从升级前副本恢复用户数据；旧版二进制无法安全读取已迁移的 schema 2 密钥或新版结果文件。
- **Windows DPAPI**：密文受当前 Windows 用户保护。拿到设置文件但没有该用户访问权的人不能解密；同一用户权限下的恶意程序仍可能访问应用数据或请求应用使用密钥。复制密文到其他 Windows 用户或设备不保证可解密，不构成可移植备份。
- **历史结果**：旧版生成结果仍可被新版读取。1.0.x 曾在新结果中写入来源证据字段（`sourceEvidence`），后续版本已停止生成，但仍接受已有结果中的可选字段以保证历史问题与答案可读，结果页和导出不显示其内容，见[历史来源字段兼容说明](source-evidence.md)。
- **旧 `github` 摘要**：旧版历史结果若包含顶层 `github` 仓库摘要，新版只会在有界读取时移除该已知字段后校验和展示；原文件与备份字节保持不变，显式恢复也保留原始字节。新生成结果和 IPC 仍拒绝此字段，加载后的旧摘要不会出现在当前结果或导出中。
