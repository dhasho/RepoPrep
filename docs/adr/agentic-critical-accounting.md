# Critical accounting envelope and causal prefix codec

Date: 2026-11-11. Status: independent offline component; no W adapter, bootstrap authorization, recovery capability, source capability or paid admission is issued here. This ADR covers only ledger-critical-envelope.ts and ledger-critical-transitions.ts. The original L/A0 implementation is unchanged.

The payload format is workflow-ledger-critical/v1, registered schemaId workflow-ledger-critical-v1. Only W schemaVersion workflow-v1 maps to ledger schemaVersion 1. Each payload carries exact originalSpecJson TEXT, provenance, a tagged event, logicalPosition and the full L state. originalSpecJson is the complete A0 canonical saved original, not an ambient current spec or constructor input. Keeping canonical JSON as a string preserves A0's supported temperature -0 through W's JSON.stringify outer encoding. The original is reconstructed once when creating a PreparedCriticalSpec cache token; its immutable data is then canonically encoded without another constructor call. The complete original hash uses A0's exported repoprep:saved-original-run-spec:v1 NUL domain and includes run/project/snapshot identities. ConfigHash uses actual fingerprintRunSpec, which deliberately excludes identities and has its existing signed-zero normalization. A prepared token or its exposed description grants no execution permission.

Canonical encoding sorts object keys, retains array order, and uses UTF-8 without a BOM or final newline. Outside the embedded originalSpecJson text, numeric signed zero normalizes to 0, matching W. Genesis is SHA256(C(["repoprep.workflow.ledger-genesis.v1", binding])) at sequence 0. A logical position is SHA256(C(["repoprep.workflow.ledger-position.v1", binding, fullProducingEpoch, sequence, completePreviousExternalReference, validatedEvent])). Its sequence equals W's global journal sequence. Current state/current physical SHA are deliberately absent from this marker, allowing the later W host to calculate it before calling L's synchronous state builder exactly once. W's external physical SHA covers the final complete outer record, including the full state, and feeds the next logical marker through its complete reference. Logical hash alone is neither full state integrity nor proof that payload provenance matches a real W outer record.

The independent W DATA descriptions preserve all binding and reference fields. Context.fence maps to provenance.producingEpoch.owner, and context.attemptId to the full epoch's attemptId. This mapping is the new adapter contract, not a claim that an adapter already implements it. Owner/attempt/attemptId all remain inside provenance and the logical marker. Inspection of sibling W's actual workflow-store.ts distinguishes MAX_CHAIN=4096 (physical attempt ordinal) from MAX_LOCAL_RECORDS=8192 (global journal sequence/reference id). Owners are 1..512 and attempt IDs are lowercase UUID v4. These parser ranges are data compatibility checks; marker/owner ancestry, actual outer metadata, configured smaller quotas and real capability validity remain W/host duties.

The seven event tags are created, model, read-reservation, read-receipt, tool-charge, recovery and seal. A model wraps the unchanged DurableModelEvent. There is no arbitrary checkpoint/import, release/refund, serialized unsent proof, recovery factory or paid operation token. created is the first sequence-1 record with null previous, matching genesis, empty rows/issued IDs, zero diagnostics and a nonterminal/unblocked state. A genuine NEW logical run and missing/unavailable storage decisions must be established outside this codec; a successful created payload cannot mint a new budget.

The causal cursor distinguishes observed accounting from accepted own events. A flush may observe other new committed RESERVED models, RESERVED reads, immutable tools, newly issued orphan IDs, a false-to-true block or existing models conservatively becoming unknown before their own flush. These observations retain cost but confer no own reservation, intent, receipt or charge qualification. Immutable commitments cannot change, observed rows/IDs cannot disappear, an orphan ID cannot later acquire a row, and new dispatched/settled rows are rejected. A model's own reservation precedes intent; accepted intent precedes receipt. Non-target usage/refunds/settlements and unknown resurrection are rejected. Context and producing epoch remain exact throughout the model's own sequence. Read receipts require their own reservation in the same epoch; tool charges can only be accepted once. A receipt with missing output can establish usage without implying a committed result.

This matches actual L timing. Models reserve synchronously before enqueuing reservation flush. Failure can retainUnknownModel and block before enqueuing unknown flush. During a projected receipt's fsync, another reservation can still be admitted against the live cap before afterFlush applies overspend/block. Capacity consistency therefore subtracts only positive receipt overspend proven by the causal chain for comparison to the original global/investigation admission ceilings. The full actual cost and exact diagnostics remain recorded, and the blocked latch cannot clear. There is no restored or additional budget. A later sampled expired/blocked snapshot cannot establish the admission-time clock or authorization; actual L final guards and genuine host issuance remain mandatory.

Epoch change requires recovery first, with from equal to the previous logical position. For a nonterminal prefix, default recovery follows actual L without optional unsent proofs: reserved models become unknown-unsent, dispatched become unknown, all other rows/usage/holds/IDs/diagnostics persist, and unresolved usage blocks. No additions/refunds are accepted. Start/deadline remain original, UTC/elapsed highwaters cannot regress. The codec validates this transformation but never calls restoreBudgetLedger or issues its structural authority. Tests may exercise L's real restore with an explicitly synthetic test authority.

seal preserves accounting/usage/IDs/diagnostics, advances time once, freezes terminal elapsed and blocks, with one completed/cancelled/failed outcome. After seal, business and late receipts are refused. A later epoch's metadata-only recovery must preserve the terminal outcome and EXACT frozen rows/accounting/time, including the state of unresolved reservations; it must not run a new unknown-conversion over sealed rows. This component does not publish a manifest or solve W's terminal publication exclusion/CAS barrier.

checkLedgerCriticalTransition prepares a private bookkeeping Step; acceptLedgerCriticalStep consumes it and the linear base cursor once, returning an immutable next cursor after the host supplies a reference. check itself does not consume the cursor, invoke a state builder, mutate a live ledger, retry an operation, write a store or manufacture a durable acknowledgment. Reference input is strict owned data. A self-consistent forged reference can pass DATA validation; the future host must match the real W acknowledgment and verified outer binding/epoch/sequence/reconstructed previous. foldLedgerCriticalPrefix accepts nonempty ordered {payload,reference} records beginning with created. Without a trusted latest-tail anchor it cannot discover an omitted suffix. The W manifest anchor and selected ledger component must later be checked against this full fold before any authorized restore.

Payloads are bounded to 64 MiB, depth 32 and 250,000 data nodes. Ordinary decoded format objects require exact plain own enumerable data, dense ordinary arrays and finite numbers, rejecting getters, proxies, symbols, nonenumerable/extra members, foreign prototypes, cycles and unsafe aggregate integers. Byte decoding pre-scans strict UTF-8 JSON for duplicate decoded keys, BOM, trailing syntax, nodes and depth before parsing. Errors have finite static codes and no data echo. A generic synchronous W payload validator may retain at most 16 prepared specs/256 KiB of canonical text, never one ambient active spec.

A Uint8Array/Buffer input is byte STORAGE, separate from decoded format data. The codec rejects proxies, foreign/subclass prototypes, empty/non-byte/oversize inputs. It reads a captured typed-array byteLength getter and copies with a captured TypedArray#set into a clean buffer; it ignores unrelated byte decorations without reading their values/getters, iterator, constructor, valueOf or length. It does not enumerate millions of integer index keys. The offline test uses a separate 64 MiB heap process to decode a 1 MiB valid padded input, an exact-input ownKeys sentinel, and malicious decorations with zero executions. A0's bounded internal original-spec byte validator remains unchanged. These bounded experiments are not a general max-payload heap guarantee.

The 64 MiB payload/data ceiling does NOT mean every legal payload fits W: its full outer record adds bytes/nodes, componentBytes may be tightened, and per-run/aggregate/control/entry ceilings apply. Source I/O/read/tool awaited durability seams, genuine recovery issuance, session drain/uncertain-ack reconciliation, latest-tail verification and terminal manifest publication remain future integration work. No provider, real profile/key/private data, native W power-loss behavior, M10 or M11 pass is claimed by these offline tests.
