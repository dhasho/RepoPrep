# ADR: P2 主进程快照、证据与预算边界

日期：2026-11-06。关联 P2、M02–M05，接口位于 `electron/services/workflow/project-contract.ts`。

快照适配器只使用现有 scanner 的私有批准记录和 project-content-reader，重新校验快照后签发不可变的脱敏读取能力。能力由 WeakSet 等程序内身份验证，复制相同字段不能成为证据。导航索引只分析已授权脱敏文本；解析失败或不支持的语言明确返回 unavailable，按行文本读取继续可用。脱敏改变行映射时，原始范围记为未知，不能冒认原始行号。

证据池只接受本快照签发的读取能力。证据 ID 由程序签发，旧 ID 的来源、范围、内容及哈希永远不变。重叠读取复用已经签发的片段，只为未覆盖的范围新增记录；同文本的不同文件仍是不同来源。容量预检失败不部分写入，不保存源码到 metadata trace。

预算账本先保留调用额度，再区分未发送、已发送、已结算或收据未知。未发送失败可以释放预留；已发送但无完整收据保守保留，不能补零。调查、生成、审查、修复、补偿和失败共用同一本账，调查不能侵占生成预留。真实收据超出预留时记录超额并拒绝新增调用，不声称本地取消可撤销服务商费用。

模型调用网关以主进程私有 profile 的规范化端点计算指纹，核对 RunSpec 的公开配置，然后调用现有 llm 客户端。`onRequest` 是观测回调，不能用其被忽略的异常实现准入；真正阻断必须在实际 fetch 前可传播的 guard 中完成。新网关尚未替换 static 生成器，因此其门禁通过不能冒充旧路径已受全局预算保护。

工具仅接受验证后的有限动作及授权文件 ID：概览、符号、字面搜索、按行读取和所属声明上下文。所有工具消费同一预算、使用 AbortSignal，返回静态失败码；不提供 shell、任意文件路径、网络或项目代码执行能力。M04 在前置模块验证后串行接入；生产默认仍为 static。
