# ADR: 子代理标注、盲评与裁定

- 日期：2026-11-06
- 状态：按用户在本次对话中的明确授权接受；取代 PLAN 早期版本要求真实人工参与的限定
- 协议：`agent-review-v1`
- 关联：P0、M06/M08/M09/M13；G1、G4、G5

## 决策与边界

任务编制、证据标注、两个独立评审者和分歧裁定者均可由 GPT-6-Luna 子代理承担。主代理负责接口、数据隔离、结果校验和整合。独立评审使用不继承实现或标注上下文的新会话，仅读取源证据、题答及 rubric；评审者之间不共享结论，不提供静态/agentic 策略标签，也不提供作者答案键。裁定者在两份评审均完成后依据源证据解决分歧，并记录裁定理由。

所有记录保存角色、代理标识、模型、输入指纹、逐样本判断、来源范围与输出指纹；只保存可核对的结论和依据，不保存隐藏思维链。名称、报告和产品文案使用“代理标注/代理评审”，不声称人工审阅。同模型、分离上下文不能消除相关偏差；报告保留该限制，不把多代理一致当作独立人类验证。

主代理另外保存实际观察到的 `collaboration.spawn_agent` 调用记录、`fork_turns=none` 配置、任务名和整合后的输出 commit；门禁核对提交 blob 与评审文件哈希。工具不提供服务商签名的会话或 token 收据，因此这是协调器观察的执行来源记录，不是密码学证明。机器门禁验证输入绑定、完整性和裁定一致性；事实判断依赖已授权的代理审阅，不能把布尔字段当作机器证明源码语义。

开发任务使用明确标为 `development-synthetic` 的源项目与固定证据；它们验证检索、装配和审查机制，不作为四个真实仓库保留集的质量成绩。任务输入和 oracle 分开存放，生产控制器不得加载 oracle；公开评审 packet 不包含标签或预期评分。保留集内容及标签只交给数据与评审代理，不交给实施代理调参。

这项授权改变评审者来源，不改变固定样本数量、质量/费用/耗时阈值，也不自动授权读取私有模型凭据或调用已配置的外部端点。M06/M08/M09/M13 的真实生成评测仍必须有实际运行、完整 usage 和已授权额度。子代理提供的静态判断不能填补缺失的 provider 收据；未运行的评测保持未完成。

## 资产及阶段门禁

P0 增加可执行的阶段检查：任务数量与分层、源文件/范围哈希、标签一一对应、公开 packet 无答案键、两份完整独立代理评审、分歧裁定、冻结 manifest/rubric/评审协议。检查数据内容，不接受资产自报通过。P0 通过后才推进 P2；P1 的静态等价性证据另行复核。完整 M11 和 M13 不因 P0 通过而自动通过。

旧 `manifest.v1.json` 与 lock 保留作为历史冻结；当前协议另写 `manifest.v2.json` 及独立 lock。以后改变评分方法或数据内容必须生成新的冻结哈希，不能追认已见测量结果。

## 回退

如以后重新要求人工复核，新增评审协议和独立结果，不覆盖本轮代理记录。关闭新策略仍沿 static 运行，现有结果与 checkpoint 不做重写。
