## Independent judgment and gate

Two isolated agents review all final main answers and all follow-up answers against the frozen source and rubric without strategy labels or author answer keys. A third adjudicates disagreements. Each record binds packet/input hashes, agent identity and source support. Agent grading is recorded as agent grading; its unavailable provider cost remains unknown and separate from generator receipts.

The material-error denominator includes every reviewed answer, including follow-ups; multiple errors in one answer are one erroneous answer, with categories recorded separately. Topic value uses the frozen four-dimension rubric. Missing review items, unresolved adjudication, incomplete usage or missing source lineage cannot pass.

The M08 gate requires the complete 48-cell matrix, valid existing question/structure contracts, zero unpacked evidence citations, candidate material-error rate no greater than control, topic-value mean at least control minus 0.2, and complete usage. Synthetic execution and report generation alone cannot pass. M13's unseen-repository matrix, release cost/latency thresholds and product switch remain separate later work.
